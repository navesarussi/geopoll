## מסקנות מרכזיות (לדיון, לא החלטות)
1. **אימות זהות:** באיחוד ה-EUDI wallet עם חשיפה סלקטיבית מתאים לעיקרון אי-הקישוריות יותר מתעודה+סלפי. מוצע ADR עתידי שיתאים את [ADR-0002](../decisions/0002-identity-gov-id-selfie-liveness.md) לכל מדינה.
2. **מנוע חלונות איסור** לפי מדינה וסוג בחירה, כרכיב כללי ולא קוד קשיח לישראל.
3. **מסלול נוער:** גבולות גיל ודרישות הסכמה שונים בכל מדינה. צריך להגדיר לכל מדינה גם גיל מינימום וגם צורת הסכמה.
4. **בלי פרסומות** הוא יתרון רגולטורי באיחוד, אחרי ש-TTPA הוציאה את Meta.
5. **מימון:** UNDEF וקרנות דמוקרטיה נותנים כסף לעמותות. זה מחזק את המבנה ההיברידי בציר 08.
6. **גודל שוק:** לא מצאנו נתון אמין, ולכן לא מוצג.
