# ADR-0016: stack טכנולוגי ל-MVP

- **תאריך:** 2026-10-22
- **סטטוס:** התקבל – אושר ע"י נוה 2026-10-22 (כפי שנכתב: TS + Rust בתחומים A/B). ספק/אזור ענן ורשימת רישיונות נשארים פתוחים (עו"ד).
- **צירים:** 06, 01, 10, 11

## הקשר
כדי שמתכנתים וסוכני AI יתחילו לבנות צריך stack אחיד. ההחלטה כפופה ל-ADR-0014 (אבטחה וחוק קודם) ול-ADR-0015 (מהירות). כל ההערכות כאן הן **הנחה** ולא נמדדו.

## חלופות שנשקלו
- **הכול ב-TypeScript:** מהיר לגיוס ולסוכני AI; חלש יותר לקוד קריפטוגרפי רגיש.
- **Flutter:** ביצועי UI טובים; שפה נוספת (Dart) ופחות שיתוף קוד.
- **מיקרו-שירותים מהיום הראשון:** נדחה – עלות תפעול; רק הגבול בין תחומי האמון קשיח.

## השלכות
- שתי שפות (TS + Rust) מגדילות דרישות גיוס. סוכני AI מטפלים היטב בשתיהן (**הנחה**).
- נעילה חלקית לספק ענן; מצומצמת ע"י IaC ו-OpenTelemetry.

## הנחות ופריטים שדורשים אימות
- **הנחה:** כל ההערכות על ביצועים וגיוס.
- **דורש אימות (עו"ד):** ספק ואזור ענן.
- **דורש PoC:** זמן הפקת הוכחה במובייל.
