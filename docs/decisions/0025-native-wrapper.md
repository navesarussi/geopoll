# ADR-0025: מעטפת נייטיב לאפליקציות (App Store / Google Play)

- **תאריך:** 2026-10-27
- **סטטוס:** התקבל (2026-10-27, אושר ע"י נוה סרוסי)
- **צירים:** מובייל, הפצה, אבטחה, פרטיות

## הקשר
האפליקציה היום היא Next.js 15 ב-Vercel. כדי להיות בחנויות צריך מעטפת נייטיב. אפל דוחה מעטפת WebView דקה לפי **Guideline 4.2 (Minimum Functionality)**, ולכן צריך ערך נייטיב אמיתי. הלקחים מ-KupaPay (Expo RN + EAS) זמינים לנו.

## החלטה (מוצעת)
**Expo / React Native + EAS**, עם שימוש חוזר ב-`packages/config`, `packages/design-tokens`, i18n ו-API קיים. ערך נייטיב שנבנה כבר ב-v1:
1. **ארנק אסימוני הצבעה מאובטח**: מפתחות ו-nullifier secrets ב-Secure Enclave / Android Keystore (`expo-secure-store`), במקום localStorage. זה ערך אבטחתי אמיתי ל-ADR-0019/0020.
2. **אימות T2 נייטיב**: צילום תעודה ובדיקת חיות דרך SDK נייטיב של ספק ה-KYC (ADR-0024), ובהמשך קריאת NFC של דרכון ל-T3.
3. **נעילה ביומטרית** לפני הצבעה חשאית (Face ID / טביעת אצבע).
4. **התראות push** על משאלים חדשים ותוצאות (opt-in, בלי tracking).
5. **מצב אופליין**: ההצבעה נשמרת בתור ונשלחת דרך ה-relay כשיש רשת.

## חלופות שנשקלו
- **Capacitor** (עוטף את ה-Next.js הקיים): מהיר יותר להתחלה, אבל ה-UI נשאר web, הסיכון לדחייה תחת 4.2 גבוה יותר, ו-SSR של Next.js לא נארז (צריך static export או טעינה מרחוק). פלאגינים נייטיב קיימים, אבל ה-UX פחות "נייטיב".
- **PWA בלבד**: בלי חנויות, אחסון מאובטח חלש יותר ב-iOS. נשאר כערוץ משלים.
- **Swift/Kotlin נייטיבי מלא**: שני קודבייסים, יקר מדי לשלב הזה.

## השלכות
- קודבייס UI שני (RN) לצד ה-web; הלוגיקה והקונפיג משותפים דרך `packages/*`.
- EAS free tier: כ-30 בניות בחודש בתור איטי. גיבוי: `eas build --local` על ה-Mac של נוה.
- חייבים מסך force-update ו-`minSupportedVersion` מהיום הראשון (קיים: `GET /api/version`, `packages/config/src/app-version.ts`).
- תוויות פרטיות (App Privacy / Data Safety) חייבות להתאים לכל SDK. **אין פרסומות** (החלטת נוה), ולכן אין AdMob ואין ATT, כל עוד לא עושים tracking.

## הנחות ופריטים שדורשים אימות
- **הנחה:** Expo SDK תומך בספק ה-KYC שייבחר (רוב הספקים מציעים RN SDK; דורש אימות לכל ספק).
- **הנחה:** אישור אפל לקטגוריה פוליטית/הצבעה. ייתכן שיידרש מידע נוסף ב-review (Guideline 5.x). **דורש עו"ד** לגבי הצהרות בחנות.
- גיל: דירוג גיל ומסלול נוער (ADR-0006) מול דרישות החנויות. **דורש עו"ד.**
