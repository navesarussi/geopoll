# ADR-0001: ריפו GitHub כמקור האמת

- **תאריך:** 2026-10-22
- **סטטוס:** התקבל
- **צירים:** כל הצירים

## הקשר
העבודה מתחלקת לעשרה צירים, וצריך מקום אחד שמתעדכן כל הזמן, כדי שלא נצטרך לחזור ולהתווכח על החלטות שכבר התקבלו.

## החלטה
ריפו GitHub פרטי בשם `geopoll`: README עם החזון והעקרונות, קובץ לכל ציר תחת `docs/axes/`, ויומן החלטות בסגנון ADR תחת `docs/decisions/`. ה-PRD v0.1 הוא נקודת המוצא, ומעכשיו הריפו הוא מקור האמת.

## חלופות שנשקלו
- Notion / Google Docs: נוח לעריכה, אבל עם היסטוריית שינויים ותהליך review חלשים יותר.
- הדף הקיים (Canvas): טוב לקריאה, לא מתאים לתהליך שינויים מבוקר.

## השלכות
- היסטוריה מלאה, review דרך Pull Requests, ובהמשך גם מקום טבעי לקוד.
- עריכה פחות נוחה למי שלא טכני.

## הנחות ופריטים שדורשים אימות
- **הנחה:** כל המשתתפים יעבדו עם GitHub.
