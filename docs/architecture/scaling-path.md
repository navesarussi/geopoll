# מסלול גדילה: MVP → ארצי → עולמי

[← ארכיטקטורה](README.md)

כל המספרים כאן הם **הנחה** לצורך תכנון קיבולת, לא תחזית.

| שלב | היקף | ארכיטקטורה | טריגר למעבר |
|---|---|---|---|
| 0 · PoC | צוות פנימי | PoC של ADR-0017 במובייל; שירותים כ-monolith מודולרי לכל תחום אמון (3 deployables: A, B, C) | PoC עובר יעדי זמן הוכחה (**הנחה**) וביקורת ראשונית |
| 1 · MVP ישראל (כנסת) | **הנחה:** עשרות אלפי משתמשים | אזור ענן אחד (בכפוף לעו"ד), DB מנוהל לכל תחום, תור אצוות לתוצאות, CDN | [mvp-israel שלב 1](../mvp-israel.md#phase-1) |
| 2 · ארצי (מקומיות) | **הנחה:** מאות אלפים | פיצול שירות תוצאות ותוכן; read replicas; מטמון תוצאות לפי רשות; קבוצות לפי רשות/תכונה | [שלב 2](../mvp-israel.md#phase-2) |
| 3 · זכויות דמוקרטיות | כמו 2 + משאלים ועצומות | ספירה שאפשר לאמת בפומבי; ביקורת חיצונית חוזרת | [שלב 3](../mvp-israel.md#phase-3) |
| 4 · עולמי | מדינות נוספות | **מודל תא לכל מדינה (cell-based):** תחומי A/B/C לכל מדינה באזור המשפטי שלה; CFG מדינתי; ספקי זהות מקומיים (EUDI, mDL – [מחקר בינלאומי](../international/README.md)) | ADR לכל מדינה |

**כלל:** לא מפצלים למיקרו-שירותים לפני שיש צורך מדוד; הגבול שאסור לחצות מהיום הראשון הוא בין תחומי האמון.
